# Portfolio Wireframe

Use approved content labels rather than filler prose.

## Generate three low-cost directions

Create three substantially different wireframes. Vary:

- hierarchy
- composition
- navigation behavior
- section rhythm
- media placement
- project presentation
- CTA placement

Do not create three color variations of the same layout.

## Evaluate each direction

Score:

- five-second clarity
- audience fit
- distinctiveness
- mobile viability
- content scalability
- accessibility risk
- implementation complexity
- performance risk
- relation to the chosen version identity

Select or combine a direction and record why.

## Output

Store the decision under `docs/design/`.
A text diagram, simple HTML skeleton, or grayscale implementation is sufficient.
Do not polish color, texture, or motion before the structure works.
