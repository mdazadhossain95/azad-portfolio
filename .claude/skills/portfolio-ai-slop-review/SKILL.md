# Portfolio AI-Slop Review

Review the rendered UI, not only source code.

Flag and fix:

- generic centered hero with interchangeable copy
- repeated three-equal-card rows
- purple gradient used without brand reason
- excessive glassmorphism
- emoji decoration
- rounded card plus arbitrary colored left border
- unnecessary pills and badges
- identical radius on every object
- default component-library appearance
- random icon styles
- vague words such as seamless, elevate, unleash, next-generation
- filler stats, fake people, fake testimonials, fake product names
- weak custom illustrations standing in for missing real assets
- typography that looks selected by habit rather than purpose
- decoration that does not support the version concept
- four versions that differ only by color

Preserve intentional brand choices. The goal is not to ban all cards, gradients, or motion; require each to serve a clear purpose.
