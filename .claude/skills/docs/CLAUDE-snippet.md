## Portfolio UI skill protocol

For every substantive portfolio UI task:

1. Read `.claude/skills/portfolio-ui-router/SKILL.md`.
2. Load the specialist skills selected by its routing table.
3. Read `.claude/skills/_shared/references/brand-system.md`,
   `version-directions.md`, and `quality-gate.md`.
4. Establish a design brief before high-fidelity implementation.
5. Do not copy reference-site source code, wording, logo, or branded assets.
6. Use shared verified content; do not invent metrics or testimonials.
7. After each substantive visual change, run the accessibility, interaction,
   AI-slop, polish, and browser-QA procedures.
8. Render the real application and verify responsive viewports.
9. Run lint, typecheck, tests, and production build.
10. Stop after the requested phase and report evidence.

Treat skill files as project requirements, not optional suggestions.
