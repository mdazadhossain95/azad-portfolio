## Semantic rules

- Use Tech Blue for primary actions.
- Use Flutter Cyan for technical highlights and the V4 pointer spotlight.
- Use FinTech Green only for verified FinTech/status information.
- Use AI Purple only for AI-related content.
- Use Burgundy and Sketch Gold sparingly.
- Use navy backgrounds as the dominant brand signal.
- Do not use every accent in one section.
- Keep normal text contrast at or above 4.5:1 and large text/UI contrast at or above 3:1.
