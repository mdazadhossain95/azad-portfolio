# Portfolio Design Direction

Start from the existing brand, repository, screenshots, and approved content.

Read:

- `../_shared/references/brand-system.md`
- `../_shared/references/version-directions.md`

## Produce a design brief before code

Write a compact brief containing:

1. Audience
2. Primary action
3. Version and route
4. Tone in three precise adjectives
5. One memorable signature
6. Dominant composition
7. Typography pairing and reason
8. Color roles
9. Density and spacing character
10. Motion character
11. Image/media direction
12. What this version must not resemble
13. Technical/accessibility constraints

## Originality rules

- Borrow principles, not source code or distinctive branded composition.
- Avoid generic centered hero plus three equal cards unless the concept truly requires it.
- Avoid decorative gradients, emoji, random glass cards, and filler statistics.
- Choose one or two bold dimensions; keep the rest disciplined.
- Match complexity to the visual idea.
- Preserve Azad’s navy-led brand while allowing each version to map accents differently.

## Approval artifact

Create or update a version brief under `docs/design/`.

Do not implement the full page until the brief and skeleton are coherent.
