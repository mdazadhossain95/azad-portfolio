# 🚀 Portfolio & UI Generator System

This system helps generate portfolio projects, UI mockups, and Upwork-ready case studies.

---

# STEP 1 — QUESTIONS

## Project Basics
- Title?
- What are you building?
- Category (Fintech / SaaS / AI / etc.)

## Scope
- Mobile / Web / Admin / All?
- Dashboard needed? (Y/N)
- Landing page? (Y/N)

## Style
- Minimal / Apple / SaaS / Dark Finance
- Colors?

## Content
- Need review? (Y/N)
- Need impact section? (Y/N)

---

# STEP 2 — OUTPUT

## Title
Short high-conversion title

## Description
Problem + solution + result

## UI Breakdown
Mobile + Web + Admin

## Features
3–6 key features

## Impact
Business / UX improvement

## Review (optional)
5-star short testimonial

## Image Prompt (4:3)
- Mobile + dashboard mockup
- Clean SaaS style
- Soft gradient background

---

# RULES
- No fake proof logs
- No sensitive info
- Clean modern design style
