## 1. What the app is
A baseball/softball **pitch-training** mobile app (Flutter/Dart; this phase targets Android). Core loop:
1. Pitcher completes a chat-style onboarding "interview" (handedness, pitches thrown, confidence 1-5 per
   pitch, and situations they like each pitch in).
2. For a game scenario the app recommends the **top 3 pitches** (ranked), biased by the profile.
3. It **speaks** the pitch, target location, count, and runners aloud (hands-free TTS).
4. The phone camera (behind the pitcher) records at **120-240 fps**; a computer-vision pipeline estimates
   **where the ball hit** a pocketed target (zone-level accuracy).
5. It shows **intended vs actual** and tracks session stats locally.

Sub-inch accuracy is NOT required - pocket/zone-level is fine. See `README.md` and `docs/` for details.

## 2. Tech stack & architecture
- **Flutter (Dart)**, single codebase, null-safety. Package name `pitch_target`.
- Modules (see `BUILD_CONTRACT.md`): `lib/models/`, `lib/data/` (scenario dataset + recommendation rules),
  `lib/services/` (engine, session builder, TTS, storage, analytics, interview), `lib/camera/` (device
  abstraction + CV: calibration homography, impact detector, pitch tracker, with Mock doubles), `lib/ui/`.
- **Native high-speed capture** via platform channels (`NATIVE_CONTRACT.md`), staged in
  `native_integration/` to install after `flutter create .` (see `native_integration/INSTALL.md`).
